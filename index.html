      Deine Fragen

        1. KI

        Die KI schreibt den Podcast, versteht deine Fragen und beantwortet sie.

        Kostenlosen Schlüssel holen: auf aistudio.google.com mit deinem Google-Konto anmelden → „Get API key“ → „Create API key“.

        Gut zu wissen: In der kostenlosen Stufe darf Google deine Inhalte (PDF-Text, Fragen) zur Verbesserung seiner Produkte verwenden. Für vertrauliche Dokumente lieber OpenAI wählen. Außerdem gibt es Tageslimits – bei sehr langen PDFs geht es dann am nächsten Tag mit „Erstellung fortsetzen“ weiter.

        Schlüssel bekommst du auf platform.openai.com → API keys (Guthaben nötig).

        2. Stimme

        Für deine eigene Stimme brauchst du ein Konto bei elevenlabs.io (Stimmen-Klonen gibt es ab dem Starter-Abo). Den Schlüssel findest du dort unter „API Keys“.

        Speicher

        Alles (PDFs, Podcasts, Schlüssel) bleibt nur auf diesem Handy. Die Schlüssel werden ausschließlich direkt an Google, OpenAI bzw. ElevenLabs geschickt.

        Datenschutz & Daten löschen

        Kurz gesagt

        Keine Cookies, kein Tracking, keine Werbung, kein Konto. Deine PDFs, Podcasts, Fragen und Schlüssel liegen nur auf diesem Gerät.

        Was auf diesem Gerät gespeichert wird

        Im Speicher des Browsers (IndexedDB): deine Einstellungen und Schlüssel, der Text deiner PDFs, die erstellten Kapitel als Audio und deine Fragen mit Antworten. Das ist nötig, damit die App funktioniert – auch offline beim Laufen. Nichts davon wird an GitHub oder sonst jemanden geschickt.

        Was wohin geschickt wird – nur wenn du es auslöst

        Wenn du einen Podcast erstellst, eine Stimme anhörst oder eine Frage stellst, schickt die App den nötigen Text (bzw. deine Sprachaufnahme) direkt an den Dienst, den du in den Einstellungen gewählt hast – mit deinem eigenen Schlüssel:

        • Google Gemini – in der kostenlosen Stufe darf Google die Inhalte zur Verbesserung seiner Produkte verwenden. Bedingungen · Datenschutz
        • OpenAI (falls gewählt) – Datenschutz
        • ElevenLabs (nur für die eigene Stimme) – Datenschutz

        Für vertrauliche Dokumente nimm besser OpenAI statt der kostenlosen Gemini-Stufe.

        Hosting

        Die App-Dateien kommen von GitHub Pages. Wie bei jeder Webseite sieht GitHub dabei technisch deine IP-Adresse. Alle anderen Bausteine (PDF-Leser, MP3-Umwandlung) liefert die App selbst aus – es werden beim Öffnen keine fremden Server angefragt. Datenschutz von GitHub

        Alles löschen

        Entfernt alle Podcasts, Fragen, Einstellungen und Schlüssel von diesem Gerät.

        Keine Cookies, kein Tracking.

        Deine PDFs, Podcasts und Schlüssel bleiben auf diesem Gerät. Nur wenn du einen Podcast erstellst oder etwas fragst, geht der Text an die KI, die du gewählt hast.
