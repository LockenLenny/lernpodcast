# Lernpodcast

PDF hochladen → die KI erklärt den Inhalt als bildlichen Lern-Podcast zum Hören beim Laufen. Rückfragen per Sprache.

Läuft komplett im Browser (Safari auf dem iPhone, „Zum Home-Bildschirm“). KI wahlweise kostenlos mit Google Gemini oder mit OpenAI; eigene Stimme über ElevenLabs. PDFs, Podcasts und API-Schlüssel bleiben nur auf dem Gerät und werden ausschließlich direkt an Google, OpenAI bzw. ElevenLabs geschickt.
